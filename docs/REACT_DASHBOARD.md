# REACT SURVEILLANCE DASHBOARD (STEP 7)

## Overview
The React Surveillance Dashboard provides a real-time, interactive command center for the IBVAP system. It connects to the FastAPI backend to visualize live camera feeds, monitor system health, and manage security alerts generated by the Event Engine.

## Architecture & Technology Stack
- **Framework:** React 18, Vite
- **Styling:** Tailwind CSS v4, Lucide React (Icons)
- **Routing:** React Router v6
- **Real-time Comms:** WebSocket (native browser API)
- **Video Streaming:** MJPEG over HTTP

## Key Components

1. **Dashboard Overview (`DashboardOverview.jsx`)**
   Displays high-level system metrics (online cameras, active alerts, total events) and provides a quick snapshot of the system's current state.

2. **Camera Grid (`CameraGrid.jsx`)**
   Lists all configured video sources, allowing operators to start/stop the underlying computer vision pipelines on demand.

3. **Camera Viewer (`CameraViewer.jsx`)**
   Displays the live annotated MJPEG stream from the selected camera, alongside a real-time log of detections and events specific to that camera.

4. **Active Alerts Panel (`ActiveAlertsPanel.jsx`)**
   A prioritized list of security alerts (e.g., Virtual Fence Intrusions) requiring operator attention. Supports acknowledgment, resolution, and dismissal actions.

5. **Event History (`EventHistoryTable.jsx`)**
   A tabular log of all structured events recorded by the system.

## Backend Integration
The dashboard relies on the following backend endpoints established in previous steps, with some additions in Step 7:

- `GET /api/v1/cameras` - Fetch camera configurations and pipeline status.
- `POST /api/v1/cameras/{id}/start|stop` - Control camera pipelines.
- `GET /api/v1/cameras/{id}/stream` - **(NEW)** Streams the latest annotated frame via MJPEG `multipart/x-mixed-replace`.
- `GET /api/v1/events` - Fetch structured events.
- `GET /api/v1/alerts` - Fetch stateful alerts.
- `PATCH /api/v1/alerts/{id}/*` - Update alert states (ack/resolve/dismiss).
- `WS /api/v1/ws/events` - **(NEW)** Real-time WebSocket feed for `NEW_EVENT`, `NEW_ALERT`, and `ALERT_UPDATED` messages.

## Running the Dashboard
The frontend is designed to be run using Vite's development server, which automatically proxies requests or expects the backend to enable CORS.

```bash
cd frontend
npm install
npm run dev
```

By default, the Vite dev server runs on `http://localhost:5173`. The FastAPI backend must be running on `http://localhost:8000` (or configured via `VITE_API_BASE_URL` and `VITE_WS_HOST`).
